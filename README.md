## 🚀 Cómo Empezar

Para probar cualquiera de los proyectos en tu entorno local:

1. **Clona este repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/Fundamentos_REACT.git
   cd Fundamentos_REACT
   ```

2. **Navega al proyecto deseado** (por ejemplo, al de Vite):
   ```bash
   cd 03-counter-app-vite
   ```

3. **Instala las dependencias y ejecuta el servidor de desarrollo:**
   Dependiendo de la herramienta usada (CRA o Vite), las instrucciones suelen ser:
   ```bash
   npm install
   npm run dev
   # o `npm start` para los proyectos de Create React App
   ```

## 🛠️ Tecnologías y Herramientas Utilizadas

A lo largo de este repositorio se emplean diversas herramientas, entre ellas:
- **React 18 / 19** - Librería principal para construir las interfaces.
- **Vite** - Para un empaquetado y servidor de desarrollo ultra rápido.
- **Create React App (CRA)** - (Para propósitos educativos y comparativos en proyectos legacy).
- **JavaScript Moderno (ES6+)** - Uso intensivo de módulos, funciones de flecha, promesas, async/await y más.
